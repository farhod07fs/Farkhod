1. Windows по-английски — «окна». Все программы в этой системе работают в окнах.
2. MS Windows — операционная система: она управляет компьютером и запускает другие программы.
3. Каждая открытая программа показывается кнопкой на панели задач.
4. Главное меню открывается щелчком левой кнопки мыши по кнопке «Пуск».
5. После загрузки системы на экране появляется рабочий стол Windows.
6. Через главное меню можно найти программы, файлы и папки — все ответы верные.
7. Окно программы закрывается кнопкой «×» в правом верхнем углу. «‒» сворачивает окно, «=» (□) разворачивает.
8. Корзина хранит удалённые файлы: их можно восстановить или удалить окончательно.
9. Программу можно запустить через главное меню, ярлык на рабочем столе или папку «Этот компьютер» — все ответы верны.
10. «Этот компьютер» показывает внутренние диски и подключённые внешние устройства.
11. Драйверы — программы, которые управляют работой устройств компьютера (и внутренних, и внешних).
12. Файл — информация, сохранённая под своим именем на любом носителе: флешке, диске, компьютере. Все ответы верны.
13. Файл — именованная последовательность байтов, то есть данные, у которых есть имя.
14. Имя файла в Windows может содержать не более 255 символов.
15. Полное имя — до 255 символов; на основную часть остаётся меньше, примерно 250 (часть занимают точка и расширение). Ответ стоит уточнить у учителя.
16. Расширение обычно короткое: 3–4 символа (txt, docx, exe). По ключу — 4.
17. В имени файла нельзя использовать знаки \ / : * ? " < > |. Буквы и цифры можно.
18. Папка (директория) — объект файловой системы, в котором хранятся файлы и другие папки (подпапки).
19. Папки, которые есть на компьютере сразу после установки системы, — системные.
20. Папки, созданные самим пользователем, — личные папки пользователей.
21. Способ хранения файлов и папок на диске называется файловой системой.
22. Диски бывают жёсткие, оптические (CD, DVD), флеш-накопители, сетевые — все ответы верны.
23. Параметры файла: имя, тип (категория), размер, дата и время изменения. «Цвет» — не параметр файла.
24. Корзина — хранение и восстановление удалённых файлов (3); «Этот компьютер» — сведения о дисках (1); «Сеть» — компьютеры локальной сети (5); «Документы» — хранение документов (2). Ответ: A–3, B–1, C–5, D–2.
25. A — монитор: «Этот компьютер» (2); B — пустая корзина (4); C — глобус с компьютерами: «Сеть» (3); D — папка: «Документы» (1). Ответ: A–2, B–4, C–3, D–1.
26. Окно — объект Windows, внутри которого можно работать с его содержимым.
27. Графическое изображение объекта называется значком.
28. Экран после загрузки системы — рабочий стол.
29. Средства, которые связывают техническое и программное обеспечение, называют интерфейсом. По ключу — интерфейс компьютера.
30. Программы, папки, файлы, значки, ярлыки и т. д. — объекты Windows.
31. Рабочий стол, окна, меню, значки, кнопки — элементы графического интерфейса.
32. Порядок хранения файлов и папок — файловая система.
33. Рабочий стол — главное окно Windows, на котором располагаются все остальные объекты.
34. Объекты Windows изображаются значками и ярлыками.
35. Курсор показывает место, где будет выполнено действие (например, куда вводится текст).
36. Свёрнутое окно показывается значком (кнопкой) на панели задач.
37. Ярлык хранит адрес (путь) к объекту — программе, папке или файлу.
38. Цифра 2 указывает на маленькие значки рядом с «Пуском» — панель быстрого запуска.
39. Цифра 3 указывает на кнопки открытых программ.
40. Цифра 5 указывает на значки возле часов — область уведомлений. Ответ стоит уточнить по рисунку.
41. Цифра 6 указывает на часы в правом углу панели задач.
42. Заголовок окна — номер 5 (3); меню — номер 4 (2); панель инструментов — номер 3 (4); кнопки управления окном — номер 2 (1). Ответ: A–3, B–2, C–4, D–1.
43. A — панель задач (2); B — заголовок окна программы (4); C — красный крестик «закрыть» (1); D — значок папки (5). Ответ: A–2, B–4, C–1, D–5.
44. A — рабочий стол (4); B — панель задач (2); C — главное меню (3); D — ярлыки и значки программ (1). Ответ: A–4, B–2, C–3, D–1.
45. Блокнот — простой текстовый редактор.
46. При форматировании меняется внешний вид текста: шрифт, его размер, абзацы, поля. По ключу — размер шрифта. Последовательность символов меняется при редактировании.
47. Форматирование меняет внешний вид текста, а не сам текст, — это не редактирование.
48. Выравнивание по ширине — это форматирование, а не редактирование. Удаление, вставка, замена символов — редактирование.
49. Прописные (заглавные) буквы набирают, удерживая клавишу Shift.
50. Backspace удаляет символ слева от курсора. Delete — справа.
51. Новая строка (абзац) — клавиша Enter.
52. Блокнот служит для создания, сохранения и печати небольших текстовых документов.
53. Пробел ставят после знака препинания, но не внутри скобок: «каскадом (друг за другом).»
54. У текстового редактора (Блокнот) возможностей меньше, чем у текстового процессора (Word).
55. Форматирование — изменение шрифта, размера, выравнивания, цвета и других параметров оформления.
56. В Блокноте нельзя оформить отдельные слова (цвет, жирный шрифт и т. д.) — форматирования там нет.
57. Язык переключают сочетанием клавиш Alt + Shift.
58. Значок документа Word — синяя буква W.
59. Документ Word — текстовый документ.
60. Междустрочный интервал измеряют в пунктах.
61. По ключу один интервал равен 6 пунктам. Ответ стоит уточнить у учителя.
62. 1 пункт = 1/72 дюйма ≈ 0,35 мм.
63. В поле «Arial» выбирают шрифт — это тип шрифта (гарнитура).
64. Microsoft Word — текстовый процессор.
65. Word входит в пакет Microsoft Office.
66. Копировать — кнопка с двумя листами (B). A — вставить, C (ножницы) — вырезать.
67. Документы Word сохраняются с расширением .docx (раньше .doc).
68. Предварительный просмотр показывает документ так, как он будет напечатан.
69. Цвет текста меняет кнопка «A» с цветной полосой (D). C — выделение цветом (маркер), A — курсив.
70. Enter нажимают в конце абзаца: внутри абзаца строки переносятся сами.
71. Гарнитура — список шрифтов (Arial, Times New Roman и т. д.).
72. Кегль — размер шрифта.
73. Вкладки можно открыть мышью или с клавиатуры — все ответы верны.
74. Лишняя буква «А» стоит справа от курсора, её удаляют клавишей Delete.
75. Пробел сдвигает текст вправо (2); Delete поднимает следующую строку вверх (4); Backspace сдвигает влево (1); Enter переносит вниз (3). Ответ: A–2, B–4, C–1, D–3.
76. Ж К Ч — полужирный, курсив, подчёркнутый (1); К — курсив (5); К Ч — курсив, подчёркнутый (3); Ж К — полужирный, курсив (2). Ответ: A–1, B–5, C–3, D–2.
77. По левому краю — кнопка 2 (строки выровнены слева); по центру — 5; по правому краю — 1; по ширине — 4 (все строки одинаковой длины). Ответ: A–2, B–5, C–1, D–4.
78. Изменение смысла — редактирование (1); изменение начертания — форматирование (2); символ — наименьший элемент текста (3); TXT — формат (расширение) текстового файла (4). Ответ: A–1, B–2, C–3, D–4.
