# Тесты · 5 класс · 1 четверть (Android)

Интерактивный офлайн-тест для Android по 9 предметам (484 вопроса), вопросы взяты из
сборника «5 класс, 1 четверть, 2026–2027».

| Предмет | Вопросов |
|---|---|

| Русская литература | 51 |

## Возможности

- выбор предмета и режима: 20 случайных вопросов, все по порядку, все вперемешку, работа над ошибками;
- три типа заданий как в сборнике: выбор ответа (A–D), соответствие (A–D ↔ 1–5), ввод числа;
- формулировки вопросов и ответов — дословно как в сборнике (рисунки к заданиям перерисованы);
- после каждого ответа сразу показывается, верно или нет, и правильный ответ;
- при неправильном ответе выводится разъяснение с проверкой (при верном — по кнопке «Показать разъяснение»);
- в конце: процент, оценка по 5-балльной шкале, список ошибок;
- лучший результат и ошибки сохраняются на телефоне, интернет не нужен.

## Как получить APK

APK собирает GitHub Actions (workflow **Build APK**) при каждом push:
вкладка **Actions** → последний запуск → артефакт `tests-5-klass-apk` → распаковать ZIP →
установить `tests-5-klass.apk` на телефон (разрешить установку из неизвестных источников).

Локально: Android Studio → Open → эта папка → Run, либо `./gradlew assembleRelease`.

## Ответы

В исходном PDF ключа ответов нет, поэтому ответы составлены по школьной программе.
Ключ лежит в `tools/build_questions.py` (переменная `KEY`, один токен на вопрос:
`A`–`D` — выбор, `4321` — соответствие для пунктов A, B, C, D, `=100` — числовой ответ).
Разъяснения к ответам лежат в `tools/explanations/<предмет>.txt` (строка `N. текст`).
После правки ключа или разъяснений выполните:

```sh
python3 tools/build_questions.py
```

Вопросы, где ответ спорный (в приложении отмечены знаком ⚠), стоит сверить с учителем:

- Русский язык: 16, 37, 44
- Русская литература: 8, 16, 28, 45
- Забони давлатӣ: 15, 33, 44, 46, 50
- Ботаника: 6, 13, 15
- История таджикского народа: 4, 5, 7, 10, 15, 26, 28, 31, 38, 48, 49
- История древнего мира: 2, 24, 38, 47
- Математика: 42 (принимаются 18 и 22 — зависит от того, входит ли 20)
- Информационная технология: 9, 54, 62

## Структура

- `app/src/main/assets/www/` — само приложение (HTML/CSS/JS), его можно открыть и в браузере;
- `app/src/main/java/.../MainActivity.java` — WebView-обёртка для Android;
- `tools/parse_pdf_text.py` — разбор текста PDF в `tools/questions_raw.json`;
- `tools/build_questions.py` — ключ ответов и генерация `questions.js`.
